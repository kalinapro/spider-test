# 🕷️ Кто ты из Человека-паука?

Увлекательный тест для VK Mini App, который поможет узнать, кто вы из мультивселенной Человека-паука!

## ✨ Возможности
- 8 захватывающих вопросов
- 8 уникальных персонажей
- Адаптивный дизайн
- Возможность поделиться результатом
